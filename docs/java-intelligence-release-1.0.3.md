# Java intelligence development build 1.0.3

Implemented and verified on macOS ARM64, 23 October 2026. The application still uses the existing custom Java2D editor and Java 25 runtime.

## Delivered behavior

- Inline semantic completion is a rendering overlay. Tab inserts the proposal and optional import as one undo operation; Escape dismisses it. Ctrl+Space opens real overload alternatives. The two completion keys and semantic commands are configurable.
- Cmd+Click, Cmd+B and F12 resolve declarations through JDT bindings, including overloaded methods, source in other files and attached JDK/library sources. Archive source is read-only. Missing source falls back to the resolved signature; no source is fabricated.
- F1 and delayed hover display actual source Javadoc and signatures. Parameter hints identify the active argument and show receiver-derived overloads. Documentation uses safe plain text and never loads remote resources.
- Alt+Left/Right restore file, caret, selection and viewport. Opening or navigating retains unsaved piece tables and independent undo histories. Quit checks every modified buffer. Saving while another buffer is visible preserves the saved file's fingerprint and version.
- Classic, Amber, Modern Dark and Modern Light work with these features. The website adds the three approved capability descriptions without altering the HelloWorld replay.

The real-window `GuiSmoke` passed edit/compile/run, errors, Stop, stdin, Isolated Run, REPL, concurrent saves, external-file protection and rapid-source version checks. `BufferSaveSmoke` passed the deterministic save-during-navigation regression and preserved undo and both versions of an externally changed file.

`IntelligenceSmoke` passed ghost acceptance/undo/dismissal, completion alternatives, four themes, three-file overload navigation, Cmd+Click, back/forward, unsaved source, actual JDK documentation and source, hover, parameter hints and incomplete-source recovery. It was also run successfully using **the final packaged application's own runtime and JAR**, with no development classes on its application classpath. The test harness alone was loaded from test classes. Installed JDK source attachments were available for the JDK-source assertions.

The final package is generated by:

```sh
TURBOJ_SKIP_BUILD=1 ./scripts/package-macos.sh dmg target/release-intelligence-1.0.3
```

This produces `TurboJ.app` and `TurboJ-1.0.3.dmg`, bundle version 1.0.3. It is a local development build, without Developer ID signing or notarization. It does not replace an already installed application.

Semantic GUI samples use 10 warmups and 30 measured requests, observed by a 1 ms Swing timer. They include context discovery and EDT delivery, but exclude the automatic completion coalescing interval and 350 ms hover delay. Paint samples use 120 synthetic key events and exclude the OS input queue, compositor and display scanout. They are not key-to-photon claims. Cold initialization remains slower; mixed cold/warm samples are retained in the reports.

## Remaining limits

See [Java intelligence](java-intelligence.md) and [overall limitations](limitations.md). Completion is conservative on unresolved or complex pattern-flow contexts. Source attachments/classpaths must already exist locally; automatic Maven/Gradle model import, binary attached-Javadoc HTML, rich Javadoc layout, Go to Implementation and automatic source downloads are not implemented. Make/Run remains a single-compilation-unit workflow. Crash recovery still restores only the last active buffer, rather than the full navigation session. Intel macOS is not verified in this session.

The next project-level priority is a shared multi-file compilation model using the same resolved classpath, followed by project tests; it should not be confused with the semantic source navigation delivered here.
