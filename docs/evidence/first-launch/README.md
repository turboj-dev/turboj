# Native first-launch evidence

Run09 is a single successful native Swing session on macOS 26.5.1/arm64 and Java 25.0.4.1. It executed 241 real AWT key events and recorded 100 PASS assertions across the Java and Maven paths. No mouse events or application command callbacks were used. See [acceptance and limitations](../../first-launch-keyboard-acceptance.md).

- [report.txt](run09/report.txt): exact assertions and entered text.
- [keyboard-events.tsv](run09/keyboard-events.tsv): monotonically measured event times and focus before/after each key.
- [checkpoints.json](run09/checkpoints.json): original state/console/editor strings and open-buffer snapshots by checkpoint ID. Dirty buffers are distinct from saved final fixtures.
- [fixtures/java](fixtures/java) and [fixtures/maven](fixtures/maven): final source/configuration actually generated by the keyboard session; transaction journals and lock files are omitted from these reproduction fixtures.
- [java-green.png](run09/java-green.png), [maven-green.png](run09/maven-green.png): unmodified native frame captures. Other screenshots remain in the local raw capture directory.
- [controls.json](controls.json): earlier failed/partial controls, including their actual failure reports and key traces.
- [build.json](build.json), [unit-tests.txt](build/unit-tests.txt), [package.txt](build/package.txt): repository source-fingerprint inventory (including tests/fixtures, not a compiler dependency graph) and verification output.
- [regressions](regressions): separate four-profile, registry and generated-reference regression results.
- [manifest.json](manifest.json): original and curated SHA-256 hashes, whole-file hashes and final harness/application identity.

Only filesystem prefixes were redacted in text: repository→`<REPOSITORY>`, home→`<HOME>`, owned temporary session→`<SESSION>` or `<CONTROL-NN-SESSION>`, other temporary root→`<SYSTEM_TMP>`. No source behavior, result, diagnostic, timing, assertion or key event was changed. PNGs were inspected and copied without editing; the two retained result captures contain no username/home path.

The manifest’s paths containing `#` identify individual UTF-8 text values in JSON bundles. Their original hashes refer to the raw file before prefix redaction; curated hashes refer to the exact extracted string, not JSON escaping. Whole-file hashes separately cover the JSON containers. This packaging reduces duplicate files while retaining reviewable raw text. The original full captures remain locally under `app/target/first-launch-keyboard-smoke-01` through `-09`; package/input provenance identifies the same uncommitted native build without pretending that the baseline Git commit already contained these changes.

Example inspection:

```sh
python3 -c 'import json; d=json.load(open("docs/evidence/first-launch/run09/checkpoints.json")); print(d["maven-green"]["state"])'
python3 -c 'import json; d=json.load(open("docs/evidence/first-launch/run09/checkpoints.json")); print(d["java-linked-rename-undo"]["buffers"]["src/test/java/tutorial/CalculatorTest.java"])'
```

The final run09 application and capture driver were compiled together in package09. The Eclipse-only Save All correction is exercised through actual Cmd+Shift+S in both workflows. The earlier coherent [run08](run08) retains its original report, checkpoint bundle and unmodified PNGs; [its manifest](controls/run08-manifest.json) and [build inventory](build08.json) record the earlier artifact and separately recompiled driver. Earlier profile raw files were preserved before rerunning the same regression on the final artifact. This is automated Swing event/focus evidence, not a manual human walkthrough or proof of physical keyboard/IME behavior.

Verify the committed files without the ignored raw capture directories:

```sh
python3 docs/evidence/first-launch/verify.py
```

On the capture workstation, `--originals` additionally checks every original raw hash, saved fixture bytes, application JAR and exact capture-driver source/class. The default check works after cloning the repository; original-file hashes remain provenance records when those local files are unavailable.
