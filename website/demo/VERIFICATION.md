## Session and evidence

The selected run, `session-2026-10-24`, began at
`2026-10-24T20:32:56.700236Z`. Its 61 full UI states span 68.354524 seconds
between the first and last recorded states. All 18 measured operation intervals
belong to this run. There are **zero timeline cuts**. Actual scripted source entry
and reading pauses are retained. Control runs are documented separately and their
times are never used in this replay.

Machine: Apple M5, 10 logical CPUs, 16 GiB RAM, macOS 26.5.1, bundled Amazon
Corretto 25.0.4.1. Spring targets and runs on Java 21. The app JVM and private
workspace/configuration were fresh; compilation warmed naturally during the
session. Maven dependencies and the verified wrapper distribution were cached
from controls. This was an ordinary development session, not a quiesced benchmark.

Verified in the actual Swing application:

- Hello World source creation, Save, explicit Compile (cache hit after live
  compilation), and Fast Run with authentic stdout and exit status.
- Two deterministic JUnit assertions: 20% discount on 1000 cents yields 800;
  zero discount preserves 1000.
- Real Rename and Extract Method forms, semantic previews, application, updated
  test references, and the same two passing tests afterward.
- Separate AutoTest on Save and AutoRun on Save. An unsaved edit can produce live
  diagnostics but does not execute tests/programs. Saving a deliberately wrong
  divisor produces one failing test; saving the correction restores two passes.
- Maven import with one module, Java 21 and 39 resolved dependencies, followed by
  explicit `spring-boot:run`, an HTTP readiness probe, real external curl with
  `Hello from TurboJ!`, and Stop Maven.

## Actual limitations retained

- Fast Run and Isolated Run terminate this Spring server after main returns;
  the demonstrated persistent service uses the existing explicit Maven goal.
- Plain Java live single-file diagnostics cannot resolve the test classpath in
  this example. The initial missing JUnit/Price diagnostics remain in the trace;
  TurboTest's workspace compilation and two tests succeed afterward.
- Some Maven lifecycle log lines are concatenated by the current output pane;
  the replay preserves them exactly rather than manufacturing cleaner output.
- Dependency import is warm with respect to artifact downloads. The 574.854 ms
  import includes configuration settling; the final model publication reports a
  separate cached 8.187 ms. No cold-network import result is claimed.
- Native previews/menu captures retain Classic colors while HTML areas follow
  the selected website theme. Narrow screens use a readable crop and can scroll
  or open the full image.
