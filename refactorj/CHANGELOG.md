# Changelog

## 0.1.0 — 2026-10-24

Initial independent Java 25 API and embedded JDT/LTK runtime; 33 typed semantic operations with applicability/conflict checks and read-only previews; shared IntelliSense workspace; UTF-16 edits; journaled transactions and undo/redo; optional generated-region FormatJ integration; independent CLI, LSP and MCP distributions; IntelliJ and VS Code adapters; native TurboJ integration; correctness and performance suites.

Eligibility limits, host-specific resource undo behavior and reproducible measurements are documented. No claim of universal semantic equivalence, fastest-in-class performance or public marketplace availability is made.
