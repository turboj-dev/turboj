# Changelog

## 0.1.0 — 2026-10-24

- Native Maven 3 effective model construction and scoped Resolver dependency graphs.
- Parent, BOM, profiles, settings, reactor dependencies and explicit repository policy.
- Immutable generations, metadata synchronization and incremental model/classpath caches.
- Toolchain/JDK selection and distinct main/test compiler configuration.
- Versioned POM previews with property/comment/encoding preservation and stale guards.
- Explicit, cancellable Maven lifecycle execution with wrapper and checksum inspection.
- Independent CLI and current MCP stdio adapter.
- TurboJ integration with shared semantic workspace, native module compilation, JUnit execution and compact explorer.

Compatibility limits and verification results are documented separately; this version has not been published to Maven Central.
